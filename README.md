# V&A Macarons & Gateaux

A modern pastry and cake shop website based in Rabat, Morocco.

## About the Project

V&A Macarons & Gateaux is a PHP and MySQL web application designed for a pastry shop. It allows visitors to explore products, order cakes, customize their cakes, and submit reviews.

## Features

- Responsive homepage
- Products catalogue
- Shopping cart
- Checkout system
- Custom cake requests
- Customer reviews and likes
- Admin dashboard
- Product management
- Order management
- Customer request management
- Multiple language support

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts – Poppins

## Requirements

- PHP 8.0 or later
- MySQL or MariaDB
- Apache server
- XAMPP or another local server

## Installation

1. Clone or download the project.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Open phpMyAdmin.
5. Create a database named `cake_shope`.
6. Import the `cake_shope.sql` file.
7. Configure the database connection in `db.php`.
8. Open the project in your browser:

   `http://localhost/mkaron/`

## Project Structure

- `index.php` – Homepage
- `Produits.php` – Products catalogue
- `custom_cake.php` – Custom cake requests
- `cart.php` – Shopping cart
- `checkout.php` – Checkout page
- `review.php` – Customer reviews
- `login.php` – Admin login
- `admin.php` – Admin dashboard
- `db.php` – Database connection
- `style.css` – Main stylesheet
- `script.js` – JavaScript functionality

## Database

Database name: `cake_shope`

The application uses MySQL to manage products, orders, customer reviews, custom cake requests, and administrator accounts.
